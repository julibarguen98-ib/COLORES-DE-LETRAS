# Colores de Letras - HTML5 & CSS3

Este proyecto consiste en replicar una maqueta utilizando **HTML5** y **CSS3**, aplicando diferentes colores de texto y una distribución ordenada mediante CSS.

## Objetivo

Reproducir el diseño de la imagen de referencia respetando la tipografía, los colores, la alineación y el espaciado de los elementos.

## Tecnologías utilizadas

- HTML5
- CSS3

## Características

- Estructura semántica con HTML5.
- Estilos de texto con múltiples colores.
- Diseño organizado en columnas usando CSS.
- Maquetación limpia y responsive.
